# The Ashened Spire — browser builds

Play in your browser:

- [Main — release version](https://cehinds.github.io/TheAshenedSpire-Web/main/)
- [Test — validated preview](https://cehinds.github.io/TheAshenedSpire-Web/test/)
- [Dev — development version](https://cehinds.github.io/TheAshenedSpire-Web/dev/)

[Choose a version](https://cehinds.github.io/TheAshenedSpire-Web/).

This repository contains compiled browser games only. Each version includes a `build-source.json` identifying its source commit. Source development remains in the private TheAshenedSpire repository.

Each version keeps its own local saves, profiles and settings. Use profile export/import to transfer a solo journey. LAN co-op requires the downloaded game server and is not available on static Pages hosting.

Artwork credits and license notices are included inside each version's `assets` directory. This delivery repository does not change those licenses.
